# **What is Machine Learning?**

**Machine Learning (ML)** is a part of Artificial Intelligence (AI) that allows computers to learn from data and make decisions or predictions without being explicitly programmed for every situation.

In simple words:

Instead of telling a computer exactly what to do in every situation, we give it examples and let it learn patterns from those examples.

## **1. How does Machine Learning work?**

Machine Learning generally works in four basic steps:

1. **Collect Data:** Give the computer information or examples to learn from.
2. **Training:** The computer studies the data and identifies patterns.
3. **Learning:** It builds a model based on the patterns it discovers.
4. **Prediction:** It uses what it learned to make predictions about new information.

Imagine your email account automatically separates unwanted emails into a **Spam** folder.

How does it know which emails are spam?

- **Step 1:** The computer is given thousands of emails labelled as either "Spam" or "Not Spam."
- **Step 2:** It studies these emails and learns patterns, such as suspicious links, repeated advertising words, and unusual senders.
- **Step 3:** It creates a model based on what it has learned.
- **Step 4:** When a new email arrives, it checks the patterns and predicts whether the email is spam.

The more useful examples it learns from, the better it can become at identifying spam.

The computer learns from examples that already have correct answers.

*Example:* Learning to identify spam emails using emails already labelled as spam or not spam.

**2. Unsupervised Learning**

The computer finds patterns and groups in data without being given correct answers.

*Example:* Grouping customers according to their shopping habits.

**3. Reinforcement Learning**

The computer learns through rewards and penalties based on its actions.

*Example:* A computer learning to play a game by earning rewards for good moves.

## **4. Where is Machine Learning used?**

Some everyday applications include:

- **YouTube:** Recommends videos based on your interests.
- **Netflix:** Suggests movies and shows you might enjoy.
- **Google Maps:** Predicts traffic and travel times.
- **Online Shopping:** Recommends products based on your activity.
- **Banking:** Helps identify unusual transactions.

## **5. Important Terms to Remember**

| Term       | Simple meaning                          |
| ---------- | --------------------------------------- |
| Data       | Information given to the computer       |
| Training   | Process of learning from data           |
| Model      | What the computer builds after learning |
| Prediction | The model's guess about new information |
| Algorithm  | The method used to learn patterns       |

**In summary:** Machine Learning teaches computers to learn from data, recognize patterns, and make predictions without needing a separate instruction for every possible situation.
