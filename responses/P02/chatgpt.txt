- **An API key is like a password:** It is a unique code that identifies your application when it wants to use another service's API. It tells the service who is making the request.
- **It controls access:** When your application sends a request with the API key, the service checks whether the key is valid and allows or denies access. Some keys also track usage and costs, so you should keep them secret.
