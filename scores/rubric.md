# Evaluation Rubric

Each response is scored on four independent dimensions. Every dimension uses a 1–5 integer scale.

| Dimension | What it measures |
|---|---|
| [Accuracy](#1-accuracy) | Whether the content is factually correct |
| [Instruction-Following](#2-instruction-following) | Whether the explicit instructions in the prompt were obeyed |
| [Completeness](#3-completeness) | Whether everything the prompt requires is covered |
| [Clarity](#4-clarity) | Whether the response is easy to understand for its intended audience |

---

## 1. Accuracy

| Score | Description |
|:-----:|-------------|
| **5** | Fully correct; no meaningful errors. |
| **4** | Correct overall; minor imprecision. |
| **3** | Partly correct; at least one notable error. |
| **2** | Major errors undermine the answer. |
| **1** | Mostly incorrect or fundamentally misleading; fails on the central facts. |

## 2. Instruction-Following

| Score | Description |
|:-----:|-------------|
| **5** | All explicit instructions followed. |
| **4** | Minor deviation with negligible impact. |
| **3** | One clear instruction violation, while the main task is fulfilled. |
| **2** | Multiple or substantial instruction violations. |
| **1** | Most explicit instructions ignored. |

## 3. Completeness

| Score | Description |
|:-----:|-------------|
| **5** | All requirements adequately covered. |
| **4** | Minor omission. |
| **3** | Important information missing. |
| **2** | Several major gaps. |
| **1** | Barely addresses the request. |

## 4. Clarity

| Score | Description |
|:-----:|-------------|
| **5** | Clear and appropriate for the intended audience. |
| **4** | Mostly clear; minor awkwardness. |
| **3** | Some confusing wording or unexplained terms. |
| **2** | Difficult to understand in several places. |
| **1** | Largely incomprehensible to the intended audience. |

---

## Scoring Principles

- **Evaluate each dimension independently.** A score on one dimension should not be raised or lowered simply because of how the response performed on another.
- **Factual errors affect accuracy.** A factual error does not automatically lower the instruction-following score.
- **Concise answers can be complete.** A concise response can still receive 5/5 for completeness if it fully answers the prompt.
- **Judge clarity against the intended audience.** The same wording may be clear for one audience and confusing for another.
- **Do not reward unnecessary length.** Extra detail that the prompt did not ask for does not improve any score.
- **Omissions can count twice.** If an explicit requirement is omitted, it may affect both instruction-following and completeness.
